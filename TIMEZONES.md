# Time Zones

Use this page to coordinate play sessions and community events across time zones.

## Shared time reference

Until the group chooses a preferred local time zone, write event times in **UTC**. Include the date and the `UTC` label so there is no ambiguity. For example: `2026-11-19 at 18:00 UTC`.

When sharing a local time instead, include the city or time-zone name and UTC offset where possible, for example `18:00 Asia/Kolkata (UTC+05:30)`. Avoid abbreviations such as `IST` on their own because they can refer to more than one time zone.

## Quick conversion

Use a world-clock or time-zone converter when planning an event. Check the date as well as the clock time: some regions change their UTC offset seasonally, while others do not.

No regular event schedule or member time-zone list has been set yet. Add agreed event times here once the group decides on them, and keep the UTC time alongside any local conversions.
