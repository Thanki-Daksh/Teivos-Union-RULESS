# Teivos Union

Welcome to the home of the Teivos Union Minecraft server group. This repository is where we can keep our community information, server rules, shared time-zone guidance, website materials, and build resources together.

## What’s here

- [Rules](RULES.md): expectations for playing and building together.
- [Time zones](TIMEZONES.md): a shared reference for planning events.
- [`base ideas/`](base%20ideas/): a place to share base concepts and Minecraft schematics.

## Getting started

If you’re joining the group, read the rules and check the time-zone guide. If you have a base idea or schematic to share, add it to `base ideas/` with a short note describing the Minecraft version and any required mods or datapacks.

This repository is a work in progress. Server address, edition, version, website, and community contacts can be added here when the group is ready to publish them.
